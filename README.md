# chi-nyc-sd-trip

Static itinerary site for the June 2026 trip: **Chicago → New York → San Diego → Los Angeles → Taipei** (Wed 6/10 depart TPE – Wed 6/24 arrive TPE).

- **`index.html`** — the rendered itinerary site. Open it in a browser; no build step or dependencies.
- **`itinerary-v3.md`** — the source of truth the site is built from.

The site covers flights & rail, hotels, a day-by-day timeline per city, suggestions, flags, and a booking checklist (checkbox state persists locally via `localStorage`).
